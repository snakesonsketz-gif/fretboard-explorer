# Fretboard Explorer

Continue/build the guitar theory app as a substantially better version of the website concept we discussed. Make the interactive visual guitar fretboard the centerpiece. Implement a polished original app for exploring CHORDS, SCALES, and ARPEGGIOS. Include deep theory, extensive chord/scale/arpeggio modifications, automatic correct conventional naming when a custom interval set matches a recognized musical structure, otherwise a clear custom formula name. For scales, implement all 7 major modes (Ionian, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian) for all 12 roots, and explicitly show the seven modal views of the same pitch collection: e.g. C Ionian / D Dorian / E Phrygian / F Lydian / G Mixolydian / A Aeolian / B Locrian, with formulas, degrees, characteristic notes, and relative-vs-parallel mode explanations. Include natural/harmonic/melodic minor, pentatonic, blues, whole tone, diminished, chromatic and other useful scales. Include triads, 7ths, 6ths, sus/add chords, extensions 9/11/13, altered dominants, diminished/augmented families, inversions/slash concepts, and custom interval editing. Add arpeggio variants and chord-scale relationships. Include a key harmonizer with I ii iii IV V vi vii°, Roman numerals, interval construction, tensions/avoid notes, substitutions, enharmonic spelling, and compare mode/chord/scale views. Support standard tuning and architecture for alternate tunings, configurable fret range, and left/right handed orientation. Add local favorites. Modern dark musician-focused responsive UI, with a large readable interactive fretboard, interval and note labels, and strong mobile support. Start with the usable application itself rather than a landing page.
